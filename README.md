## 👨‍💻 About

Welcome to the source repository for my personal developer portfolio.

I'm **Savindu Nethmika**, a student and aspiring web developer from
**Matara, Sri Lanka**. This portfolio showcases my technical skills,
projects, certificates, and development journey.

The website is designed with a modern dark interface and focuses on
presenting my work, technologies, and professional profile in a clean
and interactive experience.

## 🎨 Design

The portfolio follows a modern developer-oriented visual system built
around:

-   Dark navy backgrounds
-   Sky-blue accent colors
-   Minimal card-based layouts
-   Developer/terminal aesthetics
-   Smooth scrolling
-   Responsive layouts
-   Subtle animations and reveal effects

The objective is to maintain a professional interface while still
reflecting a software-development identity.

------------------------------------------------------------------------

## 🔍 SEO & Discoverability

The portfolio includes several SEO-oriented implementations:

-   Descriptive page title and meta description
-   Canonical URL
-   `robots.txt`
-   XML sitemap
-   Google Search Console verification
-   Open Graph metadata
-   Twitter/X metadata
-   Schema.org `ProfilePage` structured data
-   Schema.org `Person` structured data
-   Social profile references through `sameAs`

-   💻 Laptop

Navigation, project cards, typography, spacing, and interactive
